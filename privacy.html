Política de privacidad — PAMZ Google Ads MCP

Última actualización: 9 de octubre de 2026.

Qué es esta aplicación

PAMZ Google Ads MCP es una herramienta interna de uso privado. Solo la utiliza su titular para consultar y gestionar sus propias cuentas de Google Ads a través de la API oficial de Google Ads.

Datos a los que accede

Con la autorización expresa del titular, la aplicación accede a los datos de las cuentas de Google Ads del propio titular: campañas, presupuestos, métricas y conversiones. Solo los usa para analizar y ajustar esas mismas campañas.

Uso y conservación

  • Los datos no se venden ni se ceden a terceros, y no se usan con fines publicitarios.
  • Los datos no se transfieren fuera del uso descrito.
  • Las credenciales de acceso se guardan solo en el equipo del titular.
  • El titular puede retirar el acceso en cualquier momento desde myaccount.google.com/permissions.

Uso de datos de las API de Google

El uso de la información recibida de las API de Google cumple la política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.
